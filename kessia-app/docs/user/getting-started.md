# Bien démarrer avec KESSIA

_Guide utilisateur — version du 29 août 2026_

KESSIA réunit dans une seule application votre portefeuille, vos tontines,
la gestion de votre activité et un assistant. Ce guide couvre les premières
étapes.

> KESSIA n'est pas un établissement de paiement. Certaines fonctionnalités
> (Marché, Investissement, Assurance) ne sont pas encore ouvertes. Le Fonds
> de Garantie Solidaire est présenté en mode démonstration.

## 1. Créer son compte

1. **Type de profil** : particulier, entrepreneur débutant, micro-entreprise,
   PME ou coopérative. Ce choix adapte votre accueil et les suggestions de
   l'assistant ; il n'est pas définitif.
2. **Vos informations** : prénom, nom, numéro de téléphone togolais (+228),
   e-mail (facultatif), mot de passe (8 caractères minimum — un indicateur
   vous montre sa robustesse).
3. **Conditions** : acceptez les Conditions d'utilisation et la Politique de
   confidentialité. La version acceptée est horodatée ; si les documents
   évoluent, vous en serez informé et pourrez consulter la nouvelle version
   depuis le **Centre de confiance**.
4. **Vérification** : un code à usage unique est envoyé par SMS. Il expire
   rapidement — si vous ne le recevez pas, attendez une minute puis
   « Renvoyer le code ».
5. **Profil et KYC** : complétez votre profil, puis lancez la vérification
   d'identité quand vous le souhaitez.

## 2. Vérifier son identité (KYC)

La vérification débloque des plafonds plus élevés.

- Déposez les pièces demandées depuis votre espace KYC.
- Chaque statut (en attente, à corriger, validé, rejeté) est affiché avec un
  motif clair et l'aide de l'assistant.
- **Paliers et plafonds** : à chaque palier correspondent un plafond par
  opération et un plafond mensuel de sorties. Un virement refusé pour
  dépassement de plafond est normal : montez de palier pour l'augmenter.

## 3. Le portefeuille

- **Solde et historique** : toutes vos opérations, avec leur statut.
- **Envoyer** : au numéro d'un autre utilisateur KESSIA. Si le crédit du
  destinataire échoue, votre solde est automatiquement rétabli.
- **Recevoir / QR**, **Recharger**, **Retirer** : selon les fournisseurs
  disponibles.
- **Reçu** : touchez une opération pour ouvrir son reçu, imprimable ou
  exportable en PDF.

## 4. Les tontines

Quatre types : Classique tournante, Projet, Croissance, Achat — chacun avec
sa mécanique de distribution.

- **Rejoindre** : avec le code fourni par l'organisateur.
- **Contrat** : au démarrage, un contrat numérique est figé et votre
  acceptation horodatée. L'historique du groupe est consultable.
- **Cycle** : les cotisations et le versement au bénéficiaire, une fois le
  tour complet, sont automatiques. Les retards sont relancés.

## 5. Gérer son activité (Business)

- **Produits, ventes, dépenses, factures**, tableau de bord (chiffre
  d'affaires, marge, stock faible, meilleurs produits).
- **Clients (CRM)** : segmentation, fiches, notes, relances datées — les
  relances arrivées à échéance vous sont notifiées.
- **Fournisseurs** : répertoire et achats cumulés.
- **Devis → facture** : créez un devis, convertissez-le en facture ;
  numérotation automatique, impression / PDF.
- **Trésorerie & objectifs** : vues calculées à partir de vos écritures.
- **ADN de l'entreprise** : profil de santé et recommandations.
- **Plan d'affaires** : un brouillon généré à partir de votre ADN, que vous
  pouvez modifier.

## 6. L'assistant KESSIA AI

- Répond d'abord sur **vos données réelles** (solde, prochaine cotisation,
  Score, ventes du mois, opportunités) avant la base de connaissances.
- **Opportunités** : actions concrètes tirées de vos données (devis à
  relancer, clients dormants, réassort…).
- **Voix** : dictée, lecture des réponses et commandes de navigation.
- L'assistant fonctionne en mode règles : il ne réalise pas d'opération à
  votre place.

## 7. Croissance et simulateurs

- **Plan de croissance** : objectif → action → échéance → indicateur →
  progression, calculé depuis votre Score, votre ADN et vos tontines.
- **Simulateurs** : épargne / objectif, tontine, activité. Ils projettent
  vos versements **sans appliquer d'intérêt ni de rendement**.
- **Agenda** : cotisations, factures, échéances et relances regroupées par jour.

## 8. Confiance et confidentialité

- **Centre de confiance** (`/trust`) : grille tarifaire, vos plafonds KYC et
  leur consommation, éléments de sécurité, usage de vos données, documents
  juridiques et version acceptée.
- **Score KESSIA** : indicateur interne explicable (7 facteurs). Ce n'est
  pas un score de crédit et il n'est communiqué à aucun tiers.
- **Vos données** (`/profile/privacy`) : consentements, export de vos données
  au format JSON (portabilité), demande de suppression (annulable).
- **Sécurité** : activez la double authentification (TOTP) et conservez vos
  codes de secours en lieu sûr.

## 9. Besoin d'aide

Depuis l'onglet **Support**, ouvrez un ticket en précisant la catégorie
(compte, KYC, portefeuille, tontine, activité, paiement, sécurité). Vous
suivez son avancement et recevez les réponses dans l'application.

KESSIA ne vous demandera jamais votre mot de passe, un code reçu par SMS ou
un code de secours par message ou par téléphone.
